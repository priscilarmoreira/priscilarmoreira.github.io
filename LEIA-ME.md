# Publicar o site no GitHub Pages

1. Entre na sua conta do GitHub.
2. Crie um repositório público chamado SEU-USUARIO.github.io, substituindo SEU-USUARIO pelo seu nome de usuário do GitHub.
3. Extraia este ZIP. Envie index.html, style.css, script.js, .nojekyll e a pasta assets para a raiz do repositório. Não envie o ZIP inteiro.
4. No repositório, abra Settings > Pages.
5. Em Build and deployment, escolha Deploy from a branch, branch main, pasta / (root), e Save.
6. Aguarde a publicação. O site ficará em https://SEU-USUARIO.github.io/.

Para atualizar o conteúdo, edite index.html no GitHub e faça Commit changes. As alterações serão publicadas automaticamente.

O site é estático, sem instalação ou etapa de compilação. A pasta assets deve permanecer junto dos arquivos HTML, CSS e JavaScript. As fontes são carregadas do Google Fonts, com fontes alternativas locais.

Conteúdo baseado no Currículo Lattes atualizado em 02/06/2026. Revise os dados e a fotografia antes de publicar.
